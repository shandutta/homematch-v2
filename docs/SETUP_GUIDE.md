# HomeMatch Setup Guide

## What Works

- Supabase auth (email/password + Google) with protected routes
- Dashboard swipe (like/pass/view tracking)
- Couples mutual likes surfaced on dashboard
- Marketing landing pages, dynamic cards
- Liked/Passed/Viewed pages, profile/settings screens

## Prerequisites

- Node.js 24.x and pnpm
- Supabase project configured in `.env.local`

Docker + Supabase CLI (`pnpm dlx supabase@latest`) only needed for `pnpm dev:db` and `pnpm test:integration`.

## Environment

```bash
cp .env.example .env.local
```

`.env.example` is the source of truth. Fill in `.env.local`. Required:

- `SUPABASE_URL` / `NEXT_PUBLIC_SUPABASE_URL`
- `SUPABASE_ANON_KEY` / `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- `SUPABASE_SERVICE_ROLE_KEY`
- `NEXT_PUBLIC_BASE_URL`

`NEXT_SERVER_ACTIONS_ENCRYPTION_KEY` is auto-generated by `pnpm dev` if missing.

Optional integrations:

- Google Maps: `GOOGLE_MAPS_SERVER_API_KEY`, `NEXT_PUBLIC_GOOGLE_MAPS_MAP_ID`, `NEXT_PUBLIC_ENABLE_LOCATION_MAP_VIEW`
- Zillow: `RAPIDAPI_KEY`, `RAPIDAPI_HOST`, `ZILLOW_CRON_SECRET`, `STATUS_REFRESH_CRON_SECRET`, `ZILLOW_LOCATIONS`
- Vibes: `OPENROUTER_API_KEY`, `OPENROUTER_MODEL`, `VIBES_CRON_SECRET`
- Supabase proxy: `SUPABASE_LOCAL_PROXY=true`, `SUPABASE_LOCAL_PROXY_TARGET=http://127.0.0.1:54321`

Do not create or commit `.env.prod`. Production credentials stay in untracked local files.

## Local Development

### Standard dev (recommended)

```bash
pnpm dev
```

- Validates Supabase env values
- Blocks production Supabase hosts unless `SKIP_SUPABASE_GUARD=true`
- Auto-generates server action encryption key
- Starts Next.js on port 3000

No Docker, no database reset, no test user creation. Fast daily loop.

### Local DB reset/dev

```bash
pnpm dev:db
```

- Starts Docker + local Supabase
- Resets and seeds the database
- Creates test users
- Starts Next.js on port 3000

### Integration dev server

Supabase already running? Use the same command as the integration runner:

```bash
pnpm dev:integration
```

No reset, no test user creation.

### Manual Supabase start

```bash
pnpm dlx supabase@latest start -x studio,mailpit,imgproxy,storage-api,logflare,vector,supavisor,edge-runtime
```

## Approval Gate

These actions require explicit approval before execution in any environment:

- Deployments to production
- Paid API calls (RapidAPI Zillow, OpenRouter vibes generation)
- External dashboard changes (Supabase dashboard, Vercel, monitoring)
- Production database writes or schema changes
- Real user/customer data inspection
