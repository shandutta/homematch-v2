# HomeMatch v2 Accessibility Audit — 2026-05-09

Read-only audit of all public routes: `/`, `/login`, `/signup`, `/cookies`, `/about`. Conducted by hm-a11y worker via `claude -p` against live dev server on `localhost:3000`.

## Critical (6)

| # | Issue | Route | Detail |
|---|---|---|---|
| 1 | Missing `<main>` landmark | `/`, `/login`, `/signup` | Pages lack `<main>` element; existing `__tests__/e2e/no-auth-public-accessibility.spec.ts:34` will fail once run against live server |
| 2 | Decorative Like/Pass buttons capture focus | `/` (marketing) | `MarketingPreviewCardStatic` renders `<button>` elements for Pass/Like that are decorative but receive keyboard focus |
| 3 | No focus-visible styling on header/footer links | all | Header nav and footer links have no `:focus-visible` ring or outline |
| 4 | `prefers-reduced-motion` not honored | `/` (marketing) | Framer Motion animations ignore the user's OS-level reduced-motion preference; only CSS token transitions are gated |
| 5 | No skip-to-content link | all | No skip navigation link exists — keyboard users must tab through entire header |
| 6 | Logo link has no hover/focus affordance | all | Header logo link has no visible hover or focus state |

## Major (7)

| # | Issue | Route | Detail |
|---|---|---|---|
| 1 | `CardTitle` is `<div>`, not heading | `/login`, `/signup` | Auth form titles use `CardTitle` component which renders a `<div>`, not `<h2>` — forms have no heading hierarchy |
| 2 | `CtaBand` heading is `<h3>` | `/` (marketing) | Call-to-action band heading should be `<h2>` for correct document outline |
| 3 | Low contrast: `text-slate-500` on `bg-slate-50` | multiple | Contrast ratio ≈ 4.42:1 — fails WCAG AA for body text (needs ≥4.5:1) |
| 4 | Cookie banner not announced as region | `/cookies`, all | Cookie consent banner lacks `role="region"` or `aria-label` — screen readers don't announce it |
| 5 | "Google" button label lacks action verb | `/login`, `/signup` | OAuth button reads "Google" — should be "Sign in with Google" for clarity |
| 6 | Signup success swap not announced | `/signup` | Success state change after signup is not announced to screen readers via `aria-live` |
| 7 | `/cookies` and `/about` have no nav header | `/cookies`, `/about` | These pages lack the site navigation header present on other routes |

## Minor (5)

| # | Issue | Route |
|---|---|---|
| 1 | `aria-label` / visible text mismatch on hero CTA | `/` (marketing) |
| 2 | Copyright year is "2024" (stale) | all |
| 3 | Disabled submit button blocks keyboard validation surfacing | `/login`, `/signup` |
| 4 | Form error messages not linked via `aria-describedby` | `/login`, `/signup` |
| 5 | No `lang` attribute validation on `<html>` | all |

## Recommendations

1. Add `<main>` landmark to marketing layout + auth pages (critical, P0)
2. Add focus-visible ring to all interactive elements via Tailwind `focus-visible:ring-2` (critical, P0)
3. Add skip-to-content link at top of layout (critical, P0)
4. Replace `CardTitle` `<div>` with `<h2>` (major, P1)
5. Fix `text-slate-500` contrast → use `text-slate-600` or darken background (major, P1)
6. Honor `prefers-reduced-motion` in Framer Motion components (major, P1)
